LEX PROGRAM TO IDENTIFY TOKENS
================================

FILE NAME:
tokens.l


%{
#include <stdio.h>
%}

%%

"if"|"else"|"while"|"for"|"return"|"int"|"float"|"char"|"void" {
    printf("Keyword: %s\n", yytext);
}

[a-zA-Z_][a-zA-Z0-9_]* {
    printf("Identifier: %s\n", yytext);
}

[0-9]+ {
    printf("Number: %s\n", yytext);
}

"=="|"!="|"<="|">="|"<"|">" {
    printf("Relational Operator: %s\n", yytext);
}

"+"|"-"|"*"|"/"|"%"|"=" {
    printf("Operator: %s\n", yytext);
}

";" {
    printf("Semicolon: %s\n", yytext);
}

"," {
    printf("Comma: %s\n", yytext);
}

"(" {
    printf("Left Parenthesis: %s\n", yytext);
}

")" {
    printf("Right Parenthesis: %s\n", yytext);
}

"{" {
    printf("Left Brace: %s\n", yytext);
}

"}" {
    printf("Right Brace: %s\n", yytext);
}

[ \t\n]+ {
    /* Ignore whitespace */
}

. {
    printf("Unknown Character: %s\n", yytext);
}

%%

int main()
{
    printf("Enter the input:\n");
    yylex();
    return 0;
}

int yywrap()
{
    return 1;
}


UBUNTU EXECUTION STEPS
======================

1. Install Flex and GCC:

sudo apt update
sudo apt install flex gcc


2. Check Flex:

flex --version


3. Create the Lex file:

nano tokens.l


4. Paste the complete Lex code above.

Save:
Ctrl + O
Enter

Exit:
Ctrl + X


5. Generate the C source file:

flex tokens.l


This creates:

lex.yy.c


6. Compile the generated C file:

gcc lex.yy.c -o tokens -lfl


7. Run the program:

./tokens


8. Enter sample input:

if (x > 10) return y + 2;


9. Press:

Ctrl + D


EXPECTED OUTPUT
===============

Keyword: if
Left Parenthesis: (
Identifier: x
Relational Operator: >
Number: 10
Right Parenthesis: )
Keyword: return
Identifier: y
Operator: +
Number: 2
Semicolon: ;
